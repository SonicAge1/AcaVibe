## 功能一：掌握状态标记

### 交互设计
- 每张闪卡底部操作栏新增「标记」按钮，三态循环：
  - ⬜ 未标记（默认）
  - 🔁 待复习（橙色）
  - ✅ 已掌握（绿色）
- 全览网格卡片左上角显示状态角标
- 意图 Tab 的计数气泡拆分显示：总数 / 待复习数（红点）

### 数据模型变更
```json
{
  "id": "...",
  "type": "word",
  "status": "unreviewed | reviewing | mastered",   // 新增字段，默认 unreviewed
  ...
}
```

### 过滤联动
- 搜索框右侧加「状态筛选」下拉，可选：全部 / 待复习 / 已掌握

## 功能二：默写模式（Practice Hub 第一个激活的模式）

### 交互流程
1. 用户进入练习 → 选「默写模式」→ 选意图范围（全部 or 某个意图）
2. 系统随机抽取一张「待复习」卡片（没有则抽全部）
3. 展示：只显示 hint（使用场景提示），隐藏词汇/骨架内容
4. 用户在输入框手动输入，点「揭晓」
5. 对比结果：完全匹配 ✅ / 部分匹配 🟡 / 错误 ❌
6. 用户可点「标记已掌握」或「加入待复习」，然后下一题

### 评分逻辑
- 完全匹配（忽略大小写/首尾空格）= 正确
- 包含关键词（去掉冠词/介词后的核心词）= 部分正确
- 否则 = 错误
