# PM · 产品设计方案 v2

## 功能一：全览批量删除

### 交互设计
- 全览模式右上角加「选择」按钮，点击进入多选模式
- 多选模式下：每张卡片左上角出现复选框，点击勾选
- 底部出现固定操作栏：「已选 N 张」+ 「删除」红色按钮 + 「取消」
- 「全选/反选」按钮出现在操作栏左侧
- 退出多选模式：点取消 or 删除后自动退出

### 状态管理
- `selectMode: boolean`
- `selectedIds: Set<string>`

---

## 功能二：排序

### 交互设计
- 全览顶部（搜索栏右侧）新增排序下拉，紧凑展示
- 选项：最新（默认）/ 最旧 / A→Z / 待复习优先

### 排序逻辑
| 选项 | 逻辑 |
|------|------|
| 最新 | createdAt 降序 |
| 最旧 | createdAt 升序 |
| A→Z | 词汇/骨架首字母升序 |
| 待复习优先 | reviewing 排最前，其次 unreviewed，mastered 最后 |

---

## 功能三：保存后跳转提示

### 交互设计
- 现有「✓ 已保存到看板」提示保留
- 在提示右侧加一个小箭头按钮「→ 查看」，点击触发父组件切换 Tab 到词库

### 实现方式
- `ExtractorPanel` 和 `VibeTranslator` 的 `onSave` 回调调用完成后，
  触发 `App.jsx` 中的 `setActiveTab('vault')`
- 通过回调 prop `onGoVault` 传入
