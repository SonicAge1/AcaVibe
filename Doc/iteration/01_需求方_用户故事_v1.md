# 需求方 · 用户故事 v1

## 背景
AcaVibe 已完成核心功能：AI 提取骨架、翻译学术词、意图词库。
但随着词库积累，用户开始面临「存得多、用不起来」的问题。

## 核心痛点（优先级排序）

### P0 — 练习中心是空的
- 用户存了几十张卡片，但练习入口全是 Coming Soon
- **用户故事**：作为用户，我想要一个默写模式，看提示写出词汇，检验自己真的记住了

### P1 — 没有掌握状态追踪
- 用户不知道哪些词「掌握了」、哪些「还没记牢」
- **用户故事**：作为用户，我想给卡片标记「已掌握 / 待复习」，复习时优先看待复习的

### P2 — 词库无法批量管理
- 只能一张一张删，没有批量操作
- **用户故事**：作为用户，我想在全览模式下多选卡片并批量删除

### P3 — 全览模式缺少排序
- 全览按保存时间倒序，无法按字母/掌握状态排序
- **用户故事**：作为用户，我想在全览时选择「最新 / 字母序 / 待复习优先」排序

## 本轮迭代目标
优先交付 P0（默写模式）+ P1（掌握状态标记），其余排队。
