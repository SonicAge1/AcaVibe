# 需求方 · 用户故事 v4

## 迭代三回顾
✅ 自定义意图（新增/删除）
✅ 词库导入导出（JSON）
✅ 默写结算统计（正确/部分/错误 + 正确率进度条）

## 新发现的问题 & 需求

### P0 — 空词库时工具页无意图可选
- 第一次打开 App，还没有任何意图，ExtractorPanel / VibeTranslator 的意图选择器是空的
- **用户故事**：我想在保存卡片时，如果意图下拉列表是空的，能给出引导，告知可以在词库页添加意图

### P1 — 批量导入时，去重逻辑只按 id
- 如果用户手动复制了 JSON、id 相同但内容不同，会被跳过
- 改进方向：导入时如果 id 重复，应该提供「覆盖/跳过」选项，而非直接跳过

### P2 — ExtractorPanel 提取结果无法编辑
- AI 返回的骨架有时不准确，用户想手动修改后再保存
- **用户故事**：骨架提取完成后，点击结果文本可以直接编辑，编辑完再保存

### P3 — VibeTranslator 候选词无法手动添加
- AI 只生成3-5个候选词，有时用户自己有更好的词汇
- **用户故事**：候选词列表末尾加「+ 手动添加」入口，填写 word/translation/hint 后直接保存

## 本轮迭代目标
P2（骨架可编辑）+ P3（手动添加词汇）优先，体验提升最明显
P0、P1 可在本轮一起带上
