# QA · 测试用例 v1

## 功能一：掌握状态标记

### 接口测试
| # | 用例 | 输入 | 预期结果 |
|---|------|------|----------|
| 1 | 更新状态为 reviewing | PATCH /api/vault/:id { status: "reviewing" } | 200, 返回更新后 item |
| 2 | 更新状态为 mastered | PATCH /api/vault/:id { status: "mastered" } | 200 |
| 3 | 非法 status 值 | PATCH /api/vault/:id { status: "invalid" } | 400 |
| 4 | id 不存在 | PATCH /api/vault/nonexist | 404 |
| 5 | 重复 PATCH 同一状态 | 幂等 | 200，无副作用 |

### 前端交互测试
| # | 用例 | 操作 | 预期 |
|---|------|------|------|
| 6 | 默认状态 | 新卡片 | 无状态标记 |
| 7 | 状态循环 | 点击3次状态按钮 | unreviewed→reviewing→mastered→unreviewed |
| 8 | 全览角标 | 标记 reviewing 后切全览 | 卡片左上角显示橙点 |
| 9 | 状态过滤 | 选「待复习」| 只显示 reviewing 的卡片 |
| 10 | 状态过滤+搜索 | 待复习 + 关键词 | 交叉过滤正确 |
| 11 | 刷新持久化 | 标记后刷新页面 | 状态保持 |

## 功能二：默写模式

### 核心流程测试
| # | 用例 | 操作 | 预期 |
|---|------|------|------|
| 12 | 进入默写 | 点击默写模式 | 展示 hint，输入框可用，内容隐藏 |
| 13 | 完全正确 | 输入完全匹配（忽略大小写）| ✅ 绿色反馈 |
| 14 | 部分正确 | 输入包含核心词 | 🟡 黄色反馈 |
| 15 | 错误 | 输入不相关词 | ❌ 红色反馈 |
| 16 | 揭晓后标记 | 点「已掌握」| 卡片 status 更新，跳下一题 |
| 17 | 空词库 | 词库为空时进默写 | 友好提示，引导去工具页添加 |
| 18 | 只剩1题 | 做完全部卡片 | 显示「本轮完成」结算界面 |
