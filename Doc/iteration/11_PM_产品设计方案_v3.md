# PM · 产品设计方案 v3

## 功能一：自定义意图

### 交互设计
- 意图 Tab 列表末尾加一个「+ 新增」按钮（小虚线圆角胶囊样式）
- 点击弹出 inline 输入框（不用 Modal），回车或点确认保存
- 空意图（该意图下无卡片）的 Tab 上悬浮时出现「×」删除按钮
- 输入限制：最多 12 个字符；不能与已有意图重名；不能为空

### 数据模型
- `vault.intents` 数组本来就可扩展，只需要 API 层支持 CRUD

### API
- POST /api/vault/intents — 添加意图 { name }
- DELETE /api/vault/intents/:name — 删除意图（仅允许删空意图）

## 功能二：数据导入导出

### 导出
- 词库页面右上角加「导出」按钮（下载图标）
- 点击下载 `acavibe-vault-{date}.json`，内容为完整 vault.json

### 导入
- 「导出」按钮旁加「导入」按钮（上传图标）
- 点击弹出文件选择器，选择本地 JSON
- 上传后合并逻辑：新意图追加，id 不重复的 item 追加（不覆盖已有数据）

### API
- GET /api/vault/export — 直接返回 vault JSON（Content-Disposition: attachment）
- POST /api/vault/import — body: { vault: {...} } 服务端合并后返回新 vault

### 交互设计
